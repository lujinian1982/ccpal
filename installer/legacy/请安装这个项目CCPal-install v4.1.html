致 Claude Code 的部署指令

你正在阅读 CCPal 自部署包 v4。用户已经把 HTML 给你 = 意图就是装上 CCPal。 流程分两阶段:预检阶段(可主动跑环境检查命令)+ 部署阶段(用户确认后一次跑完 11 步,中途不再询问)。

🔍 阶段 1 · 环境预检(立即执行,不需用户授权)

  1. 运行 sw_vers -productName — 必须包含 "macOS"
  2. 运行 python3 --version — 必须 ≥ 3.7
  3. 运行 command -v git && git --version — git 必须存在
  4. 运行 command -v bash command -v curl command -v rsync command -v launchctl — 都必须存在(macOS 自带)
  5. 运行 ls -d ~/.claude/projects 2>/dev/null && echo OK || echo MISSING — 用户是否用过 Claude Code
预检通过(全部 ✓):向用户展示一段简短摘要 + 即将做的事,然后询问: 环境就绪。我将做以下事情(全自动,~2 分钟):
① 创建 ~/.claude/scripts/ 等目录
② 写入 13 个文件(脚本+UI+plist)
③ 合并 settings.json(让对话永不清理)
④ 加载 launchd 定时任务(每天 03:00 备份)
⑤ 启动浏览器 UI 在 http://127.0.0.1:8765

回复「是」/「确认」/「开始」即代表授权我执行全部 11 步,中途不再询问。
预检未通过(任一项 ✗):告诉用户具体缺什么,贴出修复命令(见下方 FIX 表),不要继续部署,等用户修好后说"再来一次"。

⚡ 阶段 2 · 用户回复"是"之后,顺序执行 11 步(中途不再询问)

  1. 建目录:mkdir -p ~/.claude/scripts ~/.claude/logs ~/Library/LaunchAgents ~/CCPal-Backup
  2. 提取嵌入文件:本 HTML 共 14 个 <script type="text/plain" data-ccpal-file> 块。逐个 base64 解码 → 写到 data-target 路径(~ 展开为 $HOME),覆盖同名。
  3. chmod:chmod +x ~/.claude/scripts/*.sh
  4. 合并 settings.json:读 ~/.claude/settings.json(若不存在则当 {}),把下方 SETTINGS_PATCH 字段合并(已有同名键覆盖,其他保留),写回。不要整个替换。
  5. 初始化 git 仓:如 ~/.claude/projects 存在但不是 git 仓,跑 cd ~/.claude/projects && git init -q && git config user.email claude-snapshot@local && git config user.name 'Claude Snapshot'。目录不存在则跳过。
  6. 加载 launchd:对每个 plist:launchctl unload <plist> 2>/dev/null; launchctl load <plist>。
  7. 触发首次 git snapshot:bash ~/.claude/scripts/daily-snapshot.sh(若第 5 步跳过则也跳过)
  8. 触发首次镜像备份(后台):bash ~/.claude/scripts/backup-mirror.sh & — 不必等待
  9. 启动 web UI:bash ~/.claude/scripts/start-history.sh(自动 open 浏览器)
  10. 跑自检:bash ~/.claude/scripts/ccpal-doctor.sh — 检查 23 项,自动修复缺失,完整输出展示给用户。
  11. 验证 + 报告:curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8765/api/index 应返回 200。然后告诉用户:✅ CCPal 已部署。打开 http://127.0.0.1:8765。功能:主页(对话浏览/搜索/附件/导入到新对话)、统计、健康、套餐、数据安全。重跑 ccpal-doctor.sh 可随时自检。

不可违反的约束

  • 所有写文件操作只覆盖同名,不删除其他;rm/rmdir/git reset 类破坏性命令禁止
  • ~/.claude/projects/ 内的 jsonl 是用户对话原文,绝对不动
  • 合并 settings.json 时不可替换整个文件(会丢用户配置)
  • 中途遇错:不要中断,记录后继续做下一步,最后一并汇报
  • 端口 8765 被占用:告知用户后改 history-server.py 顶部 PORT 为 8766,重启 server
  • 预检阶段可以自由跑只读命令;部署阶段必须用户回复"是"后才开始

什么是 CCPal(给人看的)

CCPal 让本机 Claude Code 对话永久保留 + 浏览器可视化检索。本地优先,零云端。

装好以后能做什么:

  • 主页 项目层级浏览,全文搜索,附件清单 Finder 一键打开,Claude Code 风格对话渲染,完整 markdown(粗/斜/删/标题/列表/表格/引用/任务/链接/代码块)
  • 统计 总会话/消息/Token + 30 天趋势 + 项目排行
  • 健康 工作节律(每日消息数 + 工作时长按 10 分钟切段)+ 共情提醒
  • 套餐 5h session / 7d weekly 滚动 Token,可标定 quota
  • 数据安全 路径清单 + 防删机制 + 复制方法
  • 导入到新对话 一键下载 markdown,拖到新对话即可续接

三层备份:① 实时 ~/.claude/projects/ 永不清理 · ② 03:00 同盘 git snapshot · ③ 03:30 rsync + git mirror 到 ~/CCPal-Backup/

幂等修复:任何时候 bash ~/.claude/scripts/ccpal-doctor.sh 检查 23 项 + 自动补缺。

给真不会用的人:文件 PREREQ.md 已经嵌入(部署后位于 ~/.claude/scripts/PREREQ.md),包含:系统要求、安装步骤、系统弹窗预期、隐私说明、卸载方法。
