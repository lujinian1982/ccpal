独立镜像

2不同工作方式的路径,统一在一起

Claude Code 的对话不管是在普通项目目录里跑、还是在 git worktree 里跑,jsonl 文件都集中写到 ~/.claude/projects/ 下,**不会写到 worktree 目录里**。

所以即使你删除某个 worktree,聊天记录也不会丢。CCPal 主页上,worktree 会自动归到它所属的真实项目下,只在条目右侧打一个 worktree 小标签。

5怎么随时把数据复制走

所有数据都是普通文件,任何拷贝工具都能搬走:

# 1) Finder 直接拖
open ~/CCPal-Backup

# 2) 命令行拷贝到外置硬盘 / iCloud / NAS
cp -R ~/CCPal-Backup /Volumes/MyDrive/

# 3) 从 git mirror 还原任意一天的版本
git clone ~/CCPal-Backup/git-mirror ~/restore-test
cd ~/restore-test && git log --oneline | head
TL;DR

聊天原文集中在 ~/.claude/projects/,不会被 Compaction 删,不会被 worktree 删除带走,自动清理已永久关闭。每天 03:00 git 打快照、03:30 镜像到 ~/CCPal-Backup/(完全独立路径),后者就算 ~/.claude 整个被清掉也还在,可随时复制到任何地方。
